# packages/core

Lógica de dominio, validaciones Zod y acceso a datos compartidos entre las 6 aplicaciones. Cero UI, cero dependencia de `next/*` (regla de CI — ver [`gobernanza/estandares/01-convenciones-codificacion.md`](../../gobernanza/estandares/01-convenciones-codificacion.md) §8).

Se construye a partir de Sprint 1 del Entregable 1, extrayendo lo que resulte genuinamente común entre `tranqi-web` y el segundo producto.
